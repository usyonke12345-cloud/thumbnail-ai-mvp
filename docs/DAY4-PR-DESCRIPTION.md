# PR #4 更新用説明

推奨タイトル：写真からの完成PNG生成・復元と採点0.4.0の表示、比較記録

入力写真と見出しからAI完成PNGを作り、失敗時も前の完成画像を保持します。写真・編集設定・完成画像をIndexedDBに保存してリロード後に復元し、PNGを書き出せます。人物や素材を保ち、写真と内容に応じて構図を設計する指示を追加しました。自動構図と文字左・文字右・見出し上の希望を選べます。

有料生成は同意と手動操作で実行します。同意は復元せず、自動再試行はありません。API試行回数は起動中の既定1回、同時実行を防ぎ、期限とエラーを表示します。回数制限はドル金額の上限ではなく、再起動でリセットされます。

PR #5の採点0.4.0・Assessment契約・契約テストを統合しました。SVG候補の未評価項目はnull、文字サイズと収まりは別項目、点数は下限〜上限で表示します。同じ未評価項目の候補をグループ初出順にまとめ、グループ内は点数降順・同点生成順にします。完成PNGは未採点で、Candidate/Assessmentとは別に扱います。

比較画面では同じ3案の画像と組IDを固定保存し、出典・許諾・評価者・順位・理由・全案不採用・失敗分類・実費・保存結果を記録できます。採点側のCSVへ変換し、既存の分析コードで集計します。採点0.4.xを受け付け、出力の重みで整合性を確認します。採点版・重み・未評価項目が異なる組は順位比較から除外します。

実際に生成した完成PNGも、入力写真とテキストを固定して構図を変えた結果ごとに比較保存できます。小さい表示で選択/全部使わない・理由・文字/主役/構図の失敗点を記録し、写真と画像付きJSONを書き出せます。画像ごとに確認済み実費とPNG保存結果を記録し、全組の記録と時間/費用/保存結果もJSONに保存できます。実費不明と0を区別し、同じ画像を二重計上しません。匿名評価者・タイトル出典・写真とタイトルの利用確認を記録します。1枚の確認、2枚以上の比較、案追加後の再確認待ちを分け、古い画像の入力条件や利用確認を推測で補いません。

PR #6の076bc4dを統合し、完成PNGの診断を接続しました。追加のPOST /api/v1/complete-diagnosticsはこのPC内だけでPNGの解析可否・寸法・相対輝度の統計とほぼ単色の兆候を調べます。同じhashのPNGは1回だけ展開し、入力・展開サイズ・役割・参照・CRC/IENDを確認します。画像を外部APIへ送信せず有料枠を消費しません。入力写真を文字なし背景として扱わず、文字・人物保持・構図の品質は未評価、assessment/qualityScoreはnullです。OpenAPIと人工fixtureを同梱しています。

受け渡しCLIは複数の画像付きJSONを検証し、SHA-256名のPNG、analysis.json、human-reviews.jsonlを非公開フォルダーへ出力します。繰り返しの書き出しでは同じ画像を重複集計せず最新の人の記録を使います。入力不明・破損画像・1枚だけ・古い選択・評価者不明の組を20件から除外し、人工/利用未確認の組と利用確認済み実タイトルの組を分けます。実際の人の記録は代作しません。各組JSONはcomplete-comparison-1.2.0（旧1.0/1.1も読込可能）、全組はcomplete-comparison-report-1.0.0です。
