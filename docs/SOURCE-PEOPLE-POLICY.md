# 元写真の人物だけを使う

生成 0.10.1（2026-10-21）。食べ物の写真からの生成で、本人が「登場しない女性が追加されている」と報告したため、全ての完成PNG生成の指示を強化しました。報告画像と本人の評価は非公開で保存し、元写真や生成応答を照合するまで、どの参考例が原因かは断定しません。

## 生成時の決まり

- 人物の唯一の出典は入力の元写真（image 1）です。顔、身体、服、表情、ポーズを保持し、同じ人物を複製しません。
- 元写真に人物がいなければ、完成画像にも人物を追加しません。食事中のモデル、商品を持つ手、顔、シルエット、人のイラストも作り足しません。
- 通常生成、手動の字体・配置指定、素材の再構成、過去の評価メモあり、参考例ありの全てに適用します。再構成で許可するのは元からある人物・物の切り抜きや移動であり、新しい人物の生成ではありません。
- 参考の人物を必要とする型は見送るか、元写真の物や文字で成立するようにします。タイトル、イメージ、参考の観察文や画像、過去の評価は人物追加の根拠になりません。
- 修正元の完成PNG（image 2）にだけいる人物は、変更指示の対象外でも除きます。文字だけの修正であっても、前回の誤った追加人物を保存し続ける指示にはしません。

人物を新しく作る設定や許可の項目は追加しません。入力写真にいる人を使う再構成は引き続き選べます。

## 記録と互換性

生成版を `ai-complete-0.10.1` にし、結果の limitations とエディターに方針を表示します。入力・応答のキー、Candidate / Assessment、採点、重み、画像枚数、モデル、medium品質、料金制限は変更しません。OpenAPI 0.3.8 は説明だけを追記し、人工fixtureの生成版を合わせます。新しい依存もありません。

生成側の解析では0.10.1も評価メモの有無が分かる既知の版に追加します。過去の未知の版まで評価済みと扱う拡張や、採点側の実装変更は行いません。

A入力固定は、生成指示・コード・版の変更を検出し、古い固定IDのまま生成しません。比較用のChatGPT依頼文にも同じ人物の制限を追加します。過去の画像・評価や固定条件は書き換えません。生成指示、固定用の比較文、OpenAPIの説明は相互レビュー対象です。

## 検証と限界

無料のテストでは、送信直前の画像編集リクエストを検査します。全designと見出し方式、手動配置、人物を含む参考・評価メモ、修正元、Aの固定文に人物の制限が伝わること、元写真が1枚目であること、追加の生成呼び出しを行わないことを確認します。公開fixtureに実際の写真は含めません。

これはプロンプトによる制約です。入力と出力の人物を自動検出・照合して違反画像を止める機能ではなく、人物の無追加や画素の保持を保証しません。有料の実画像確認は自動実行せず、元写真と完成画像で本人が確認します。追加人物が出た場合は失敗として記録し、元写真に基づいて修正します。

OpenAI Docsの[画像編集の指示](https://developers.openai.com/api/docs/guides/image-prompting)に沿って、変更対象と保持条件、各画像の役割を明示します。指示を強化したことと、実画像で再発しなくなったことは分けて扱います。
