# 写真の加工を控えめにする

2026-11-01。生成0.12.0の3枚写真の出力に、本人から「写真の加工度がすこし強い。あとはいい」という評価がありました。JSONは入力3枚、100実例から参考5件、生成0.12.0として照合済みです。元データと発言は非公開で保持し、人の選択や点数を推測で補っていません。

通常エディターの生成を0.12.1にし、写真の仕上げについて次を明記します。

- 元の明るさ・色・肌の質感・ピントの柔らかさを基準にし、見えるようにする小さい補正にとどめる。
- もとの写真が少しぼけていても、顔・髪・肌の細部をAIで描き起こして鮮明にしない。過度な美肌化、シャープ処理、HDR、彩度・コントラストの強調を避ける。
- 別々の写真の照明を、無理に同じ強い色調へそろえない。
- 100実例の観察は主に字体・文字の階層・余白・構成へ使い、元写真へ加工感やライティングを転写しない。
- 人が写真をそのまま並べる構成を指定した場合は、全体の切り取り・拡縮を使う。recomposeが選ばれていても、不要な人物切り抜きを強制しない。

入力写真の構成指定、見出しの作り方、参考候補の選定、モデル・medium品質・1536×864・出力1枚・自動再試行なしは維持します。変更はreferenceMode requiredの生成指示に限定し、旧APIの単一写真0.10.2・複数写真0.11.0は維持します。

0.12.0の保存画像と評価は書き換えず、読込可能なまま保持します。新しい指示ファイルを無料入力固定のコードハッシュへ含め、古い入力固定のまま新しい指示へ差し替わることを防ぎます。OpenAPI0.3.10の構造は維持し、0.12.1の参考記録条件と説明、人工fixtureを更新します。shared/解析互換性は相互レビュー対象です。採点値、Candidate/Assessment、pipeline、data/scoring、依存は変更しません。

これは画像モデルへの指示で、画素が同一の切り抜きや肌・顔の保持を保証する機能ではありません。[公式の画像プロンプトガイド](https://developers.openai.com/api/docs/guides/image-prompting)も、指示後の結果確認と、画素を固定する必要がある場合の合成を区別しています。今回の自動テストは送る指示・1回の呼出し・版・旧記録の互換性を確かめるもので、新版の実画像で加工が弱まったことは未確認です。有料の確認生成は実施していません。
