# Day 3 — PNG保存とレイアウト

作業ブランチ: feature/day3-png-export。生成側Day 2から分岐し、未マージの共有契約を含みます。

## 実装したこと

画面の各候補にPNG保存ボタンを追加。保存済みSVGをブラウザのcanvasで1280×720のPNGへ変換します。
追加API呼び出しなし。SVG保存も維持。保存失敗時の表示と、変換中の連打防止を追加。
APIは従来のSVGを返し、mimeTypeや採点契約は変更しません。

## 検証

構文確認と既存15テスト成功。これはブラウザのPNG変換の成功を保証するテストではありません。
ブラウザで画像を生成し、PNG保存後の寸法・日本語・背景・文字切れを確認する作業が残っています。
