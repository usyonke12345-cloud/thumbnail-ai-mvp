# 理想のサムネを基準にする検証

目的はモデルの追加学習ではなく、目標の作風を具体化して生成方法を比較することです。
対象ジャンルを1つ決め、最初は自作または利用許諾済みの画像5〜10枚で開始します。
実画像・記入済みの表はPC内の非公開フォルダに保存します。GitHubにはこの手順と空の表だけを置きます。

## 収集と分析

1. reference-catalog.template.csvをコピーし、画像ID、出典、利用許諾、好きな理由を記録。
2. 文字の行数・量・大きさ、主役の位置、背景の密度、配色、余白、装飾を画像ごとに整理。
3. 共通の特徴を3〜5項目の作風ルールにまとめる。人物の顔・ロゴ・独自表現をそのまま複製する指示は避ける。
4. 画像をAPIへ送る方法は、送信先・枚数・費用を説明してから試す。初回は画像を送らず、分析した作風を文章で指示する比較も可能。

## 比較方法

- 同じタイトル、モデル、品質、サイズで、現在の方式と作風ルールを使う方式を比較する。
- 実験前に生成回数と予算を決める。やり直しも回数に含める。
- 大きい表示と幅360pxの表示で比較。表示幅は仮値。OS・ブラウザ・ズームを揃える。
- 候補の名前をA/Bとして、どちらの方式か隠して評価する。参考画像の順番や方式の表示による誘導を減らす。
- 評価項目: 文字を読めるか、タイトルとの一致、主役の分かりやすさ、構図・配色の目標への近さ、実際に使いたいか。
- 人が選んだ案と理由を記録。採点スコアや再生数を正解として扱わない。CTRの効果保証はしない。
- 未使用のタイトルでも確認してから共通ルールへ採用する。

## 分担

生成担当: 参考画像の特徴を生成指示・レイアウトへ反映し、同条件の比較案を作る。
評価担当: 記録形式と評価方法をレビューし、人の評価を集計する。
この収集表は作風分析用。B2の許諾済み20タイトルや既存の選好記録表を置き換えません。

## 初回に必要なもの

対象ジャンルと、参考画像5〜10枚（まず3枚でも分析開始可能）。
ユーザーが好む理由を一言ずつ添える。未確認の許諾を確認済みとして記録しない。
参考URL3本と好みの理由は受領済み。C3を作風例として試作し、ユーザーが採用しました。体系的な画像収集・複数基準の比較・追加学習はこれからです。Day4の手順はdocs/DAY4.mdを参照。
