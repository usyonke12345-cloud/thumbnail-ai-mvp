# 元写真と完成画像の人物範囲（試作・2026-10-13）

写真を保てているかを今後調べるため、元写真と完成PNGの同じ主役を、人がそれぞれ四角く囲んで記録する。指定・保存・解除・書き出しは無料で、外部通信や生成は行わない。現時点では、人物の自動検出・同一人物判定・保持率の点数は未実装。範囲を指定しても写真の保持が確認できたとは扱わない。

## 操作

1. `/editor`の比較一覧で完成画像を選ぶ。
2. 画像下の「人物範囲を記録（無料・手動）」を開く。
3. 元写真と完成画像で、同じ主役をドラッグして囲む。左・上・幅・高さを数値でも調整できる。
4. 比較記録の評価者IDを確認し、「両方の人物範囲を保存」を押す。
5. 共有ZIPまたは比較JSONを書き出すと、範囲も含まれる。

写真全体の座標で保存する。画面の表示幅が違っても、元写真は1280×720、完成画像は1536×864の画素位置へ変換する。範囲は画像内、1px以上、整数の四角形。顔だけ／頭と上半身など、どの部位を囲んだかの統一と、実際の使いやすさは人の確認が必要。

範囲を解除すると、両方のrect:nullと解除日時を記録する。古いZIPを読み直しても解除を戻さない。片方だけの指定、未知の測定方法、ハッシュ・寸法の不一致は拒否する。元写真が記録されていない画像では使わない。写真と品質確認の理由、画像の組ID、PNG本体は変えない。

## 採点側へ渡す形式（相互レビュー対象）

`images[].subjectRegions` は任意項目。正規化例は `docs/fixtures/subject-regions.json`（人工の座標とハッシュだけ）を参照。

- version: `subject-regions-1.0.0`
- recordedAt: 人が保存／解除した日時
- reviewerId: 匿名ID（r01など）
- method: `manual`
- coordinateSystem: `image_pixels`
- sourcePhoto: 元写真のsha256、width:1280、height:720、rect
- completeThumbnail: 完成PNGのsha256、width:1536、height:864、rect
- rect: `{x, y, width, height}`、または解除を表す `null`。両方指定、または両方null。

元写真のハッシュは固定入力のsourceSha256、完成PNGのハッシュはimageSha256と一致すること。画素の対応点・セグメンテーション・文字領域ではなく、人が選んだ四角形。輪郭や人物IDを推測で補わない。自動検出を追加する場合は、methodと版を改めて共同設計する。

人物範囲のある組は `complete-comparison-1.7.0`。全組reportは既存の1.1.0、解析datasetは `complete-evaluation-dataset-1.5.0`。旧組1.0.0〜1.6.0と旧reportを維持する。同じ画像の範囲は新しいrecordedAtを採用し、同時刻で内容が違う場合は拒否する。解除も新しい記録として扱い、画像の固定情報を変更しない。

解析datasetへ範囲を渡し、PNGの展開結果や画素は保持しない。採点側の彩度・色分布関数への自動接続はしない。色の分布が似ていても人物の描き直しは判断できず、範囲を使った検証が別途必要。正式な20件の件数は増やさない。

新しい静的配信は `/subject-regions.js` のみ。HTTP API、Candidate/Assessment、画像資産1.0.0、生成版、診断版、依存パッケージは変更しない。範囲の記録形式・解析への受け渡しは採点担当のレビュー対象。実写真・範囲の実記録は非公開で扱う。
