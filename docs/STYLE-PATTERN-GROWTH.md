# イメージだけ指定し、使える構成を増やす

生成版ai-complete-0.4.1。利用者は写真・動画タイトル・内容と、希望するイメージを入力する。見出し、字体、文字サイズ、配置はAIに任せられる。イメージは自由文300文字以内で、8つの雰囲気の例は入力の補助であり、完成サムネや字体の指定ではない。詳細指定は任意とし、雰囲気の例を選ぶとdesign/compositionをautoへ戻す。

## 生成の組み合わせ候補

shared/complete-designs.mjsのCOMPLETE_PATTERN_SEEDSに追加していく。初期の8件と、本人が使えると確認した1枚の特徴を参考にした追加の1件、合計9件を持つ。すべてexperimentalで、別入力での再現性を確認したパターンではない。AIが写真の主役と余白・動画内容・希望するイメージから選択または調整する。固定の順番や、選んだ雰囲気からの一対一の割り当てにはしない。実フォント・座標・選んだ候補名は未取得で、推測保存しない。

## 本人の確認から追加した候補

2026-10-11、希望するイメージとして「ゆっくりした旅の雰囲気。写真を自然に見せ、文字も穏やかに。」が入力され、本人が貼り付けた完成画像を「このまま使える」と確認した。その1枚の手書き風の短い2段組と、顔を避けた余白の使い方からrelaxed_handwrittenを追加した。落ち着いた雰囲気を特定の字体へ一対一に固定せず、写真と内容に合う場合の候補にする。

画像と本人の発言はGit除外のdata/private/style-evidence/に保存する。正式なAPI画像ID・生成版・入力写真のハッシュ・実費・表示幅・許諾・具体的な選択理由は未取得で補わない。本人の使用可の確認と、アシスタントによる見た目の観察を分ける。ブラウザの正式な比較記録や20件の複数案比較へは推測で登録しない。モデルがこの候補を選択した証拠ではなく、追加した指示の再現性は次の実画像で確かめる。

## 実画像で増やす手順

1. 同じ入力写真・タイトル・内容・イメージを固定して、少数の完成PNGを手動生成する。1回1枚、medium、起動内上限と確認チェックを維持する。表示や比較だけでAPIを呼ばない。
2. 本人が168 / 246 / 360pxなどの小さい表示でも読み、雰囲気・文字・人物と素材の保持・余白を確認する。幅は仮の確認用で、プラットフォームの固定寸法とは扱わない。
3. 使いたい案・理由・気になる点・実費・保存結果を既存の比較画面で記録する。「全部使わない」や「まだ直したい」も保存し、無条件に成功例にしない。1枚の確認と2枚以上の比較を区別する。
4. 本人が実際に使えると判断した画像を、画像付きJSON・入力写真・生成版・イメージとともに非公開で保存する。生成AIがその候補名を選んだとは推測せず、人が見た構成・字体の特徴を別の観察としてまとめる。
5. 別の写真・短い/長い見出し・異なる主役位置でも試し、何に向くか、何に向かないかを確かめる。失敗例がある候補は用途を絞るか修正する。合格枚数や評価理由をAIが埋めない。
6. 良かった組み合わせから、生成の指示を少しずつ追加・修正する。必要なAPI・書き出し形式の変更は採点担当と合わせる。記録保存はモデルの自動学習ではなく、検証と指示改善に使うためのもの。

9候補の別入力での使える品質の確認、写真保持・文字・構成の自動採点、実フォント抽出は未完。本人による1枚の使用可の確認を、9候補全体や別の写真の品質確認として数えない。完成PNGの明るさの診断を品質点数やCTR予測にしない。参考画像を使う場合も、人物や素材を複製する指示として使わない。

## 共有と互換

APIに任意のvisualIntentを追加する。省略・空欄では動画内容からAIに任せる。design/compositionの明示指定があれば優先する。画像編集APIの同じ1回で判断し、分析用の追加APIを呼ばない。元写真、モデルgpt-image-2.5-flare、medium、1536×864、1回1枚は維持する。

イメージを入れた比較JSONはcomplete-comparison-1.4.0、分析用analysis.jsonはcomplete-evaluation-dataset-1.2.0。イメージが違う入力は別の組にし、空欄では従来の組ID・形式を維持する。旧1.0.0〜1.3.0も読める。画像資産image-assets-1.0.0とCandidate/Assessmentは変更しない。採点担当は最新のコードを取り込んでから新形式のJSONを読む。相互レビュー対象はOpenAPIの任意入力、共有カタログ、比較・分析形式で、評価の点数や重みは変えていない。

指示の参考：[OpenAI Docsの画像プロンプトガイド](https://developers.openai.com/api/docs/guides/image-prompting)。仕上がり・字体・配置の希望と、人物や環境を保持する条件を分けて書き、実画像で結果を確かめる。
