# 参考サムネからの作風基準案

2026-10-08に公開サムネを目視確認。画像は保存・コミット・API送信しない。以下は観察と設計上の仮説であり、学習済みモデルやCTR予測ではない。

## 参考5：対比イラスト型

出典: https://youtu.be/HBluLfX2F_k

ユーザーの好み：構図、イラストの配置位置。

観察：右上に2行の大きな白い文字。左下の灰色の人物群と右下の赤い人物を、斜めのシーソーがつなぐ。文字と人物の主な領域を分け、赤が人物の対比を強めている。背景は黒系で、グラフや点の装飾が控えめに見える。

基準案：文字とイラストを別の主領域へ置く。集団と1人など意味のある対比を配置で伝える。強調色は主役に集中させる。装飾は主題より弱くする。人物の具体的な造形、シーソー、文字そのものを複製する必要はない。

比較用の人工案：D1上文字・下イラスト、D2左文字・右イラスト、D3中央文字・左右イラスト。同じタイトルと簡単な図形で比較する。各案で図の縮尺も変わるため、配置単独の因果検証ではない。scripts/style-studies.mjsで無料作成できる。本番生成や採点契約へはまだ組み込まない。

## 参考4：文字・人物・アイコン型（好みは未確認）

出典: https://youtu.be/i72HxjCLlYY

観察：左に複数行の大きな白い文字、中央から右に人物、上側から人物周辺に色のある複数のアイコン。コードの画面が背景にあり、下左に金額の文字がある。

設計仮説：大見出し、人物、補助アイコンの優先順位を付ける型として使える。ただし情報量が多く、縮小時にアイコンや金額が読めるかは別途確認が必要。ユーザーが好む箇所を推測して採用しない。
