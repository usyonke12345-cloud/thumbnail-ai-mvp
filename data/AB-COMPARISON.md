# このサービス と ChatGPT 直接 の比較（差別化の仮説Aの検証）

目的：同じ写真・同じタイトルから作ったとき、利用者が「このサービスの完成PNG」と「ChatGPTに直接頼んだ画像」のどちらを使いたいかを、どちらで作ったか分からない状態で確かめる（Issue #9）。好みの比較で、CTRや品質の保証ではない。

## 1. 組を決める（生成する前に）
- 5組以上。写真とタイトルは、作る前にリストで決めて書いておく（結果を見てから選ばない）。
- 写真は本人が撮ったもの、写っている人の同意が取れているものだけ。タイトルは自分の動画のもの（他人のタイトルは使わない）。
- 種類を混ぜる：人物の自撮り／人物＋背景が主役／屋内・屋外、タイトルの長さ（短い・長い）、日本語・英語。

## 2. 画像を作る（どちらも1回だけ・作り直さない）
公平にするため、**どちらも最初に出た1枚を使う**。気に入らなくても作り直さない（失敗も結果）。

- **このサービス**：`/editor` で写真とタイトル（＋内容）を入れ、設定は既定のまま（構図・デザインはAIに任せる、評価メモは使わない）で1回生成し、PNGを保存。
- **ChatGPT**：新しい会話で写真を添付し、次の文をそのまま送る（`{}` を置き換える）。1回目の画像を保存。

  ```
  この写真を使って、YouTube動画のサムネイル画像を作ってください。
  横長（16:9）でお願いします。
  動画タイトル：「{タイトル}」
  動画の内容：{内容。無ければこの行を消す}
  タイトルの文字をサムネイルの中に入れてください。写真の人物はそのまま使ってください。
  ```
- 日付、ChatGPTの画面に出ていたモデル名・プラン、このサービスの生成版（例 ai-complete-0.6.0）をメモしておく（各組の meta.json に書く）。

## 3. ファイルを置く（非公開・Gitに入れない）
```
data/private/ab/
  pair01/ source.png   service.png   chatgpt.png   meta.json
  pair02/ ...
```
- 組ID（フォルダ名）は英数字・`-`・`_`。画像は png / jpg / webp。
- meta.json の例：`{"title": "動画タイトル", "brief": "内容（任意）", "serviceVersion": "ai-complete-0.6.0", "chatgptModel": "画面の表示", "date": "2026-10-14"}`

## 4. 比較シートを作って評価してもらう
```
node data/ab-compare.mjs sheet data/private/ab r01
```
- `ab-review-r01.html`（比較ページ）と `ab-review-r01.csv`（記入用）を評価者に渡す。**`ab-key-r01.json`（どちらが案X/案Yかの対応表）は渡さない。**
- ページには「案X」「案Y」とだけ出る。どちらがこのサービスかは評価者ごと・組ごとに入れ替わる。
- 記入：`preferred`（X / Y / same）、`would_use_x` / `would_use_y`（yes / no、手直しなしで使うか）、`reason`（一言）。
- 評価者は本人に加えて、できれば開発に関わっていない人を1〜2人（r02, r03 …で同じ手順）。

## 5. 集計する
```
node data/ab-compare.mjs summarize data/private/ab ab-review-r01.csv ab-review-r02.csv
```
- `preferred`：このサービス／ChatGPT／差なし が選ばれた回数。
- `signTestP`：差なしを除いた両側二項検定。5組で5対0なら0.0625、4対1なら0.375。少数なので「偶然でも起こりうるか」の目安で、0.05を超えても「差がない」とは言えない。
- `wouldUseRate`：手直しなしで使うと答えた割合（方法ごと）。
- `reasons`：理由の一覧（どちらを選んだかを対応表で戻したもの）。

## 結果の読み方
- **このサービスが多く選ばれる**：理由（文字・写真の保ち方・構図など）が差別化の中身になる。
- **差がない**：価値は「比べる・記録する・好みに近づける」（仮説B）や「文字の正確さ」（仮説C）に絞る。
- **ChatGPTが多く選ばれる**：方針を考え直す材料。早く分かるほどよい。
- どの場合も、人数・組数が少ないうちは参考値として扱い、判断は理由の中身とあわせて行う。
