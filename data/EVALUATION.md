# 採点の版・限界・検証状況（B6 下書き）

最終更新: 2026-10-09（B担当）。**下書き**です。検証データ（B2・B5・縮小表示テスト）がそろった時点で「検証結果」を埋めて確定します。

採点の出力は**レイアウトの仮説的な指標**です。クリック率（CTR）の予測でも、効果の保証でもありません。人の選好の記録もCTRではありません。

## 1. 現在の版（採点 0.4.0）

- `kind`: `layout_heuristic`（0.1.0 から変更なし）
- 項目と重み（%）：`contrast` 50 / `brevity` 30 / `font` 10 / `fit` 10。**仮説で、実データで校正していない**。出力の `weights` にも同じ値を返す。
- 閾値：文字サイズは48px以上で満点（**検証前の仮値**）、短さは15文字まで満点（仮説）、コントラスト比は7で満点。
- 評価できない項目は `null`。総合点は「未評価を0点とした下限 `overall`」〜「満点とした上限 `overallMax`」の幅と、評価できた重みの合計 `coverage` で示す。幅は計算上の範囲で、統計的な信頼区間ではない。
- 契約：`shared/openapi.json` の `Assessment`、説明は `docs/API.md`。採点の出力が契約に合うことは `tests/assessment-contract.test.mjs` で確認する。

## 2. 版の履歴

| 版 | 主な変更 | 点数への影響 |
|---|---|---|
| 0.1.0 | 初期実装。メタデータの配色・文字数・文字サイズ（76px基準）から採点 | — |
| 0.2.0 | SVGの文字領域を解析。背面が単色の矩形と確認できたときだけ画像内の色でコントラスト。文字サイズの基準を48pxへ | AI背景（48px）の `font` が下がらなくなった |
| 0.2.1 | はみ出しを上方向も判定。パネルに一部だけ重なる文字をパネル基準で判定 | 上・パネル外へはみ出す案の `font` が下がる |
| 0.3.0 | `metadata.textLayout` v1 で収まり・コントラストを評価。無い・未知の版はSVG解析へ | `textLayout` の無い候補は変化なし |
| 0.3.1 | 背面が単色と確認できないときはコントラストを0点（配色で代用しない） | 背面が画像・不明の案は総合点が最大50 |
| 0.3.2 | 画像の欠損・破損・形式不一致を確認し、その場合は文字配置を評価しない | 使えない画像の案は総合点が最大50 |
| 0.4.0 | 未評価を `null` に。`fit` を独立（`font` は文字サイズのみ）。`overallMax`・`coverage`・`unevaluated`・`weights` を追加 | 契約変更。寸法不明の案は `fit` が未評価になる |

## 3. 何を評価し、何を評価していないか

| 対象 | 状態 |
|---|---|
| タイトル文字と単色の背面のコントラスト | 評価する（`textBackdrop` が `solid`、またはSVGで単色の矩形と確認できた場合） |
| 背景画像の上の文字のコントラスト（AI背景C3など） | **未評価**（`null`）。実画像の分析が必要 |
| 文字の収まり（配置領域からのはみ出し） | 評価する（寸法が測定済みの場合）。生成側の寸法は `estimated`（実フォントの測定値ではない） |
| 絵文字など寸法が不明な行の収まり | **未評価**（`null`） |
| 文字サイズ・文字数 | 評価する（基準は仮説） |
| フッターなど小さな文字 | 単色の背面ならコントラスト比4.5未満を根拠に書く。点数には入れない |
| 画像の内容・構図・人物・ジャンル適合 | **未評価** |
| 写真から作る完成PNG（PR #4、`/api/v1/complete-thumbnail`） | **採点しない**（Candidate / Assessment とは別の出力） |
| 縮小表示での読みやすさ | **未検証**（48px満点は仮値） |

既知の問題：デモの3案はすべて100点の同点で、採点が案の違いを区別できていない。同点の組では1位の一致を判定できないため、B5では `top1_tie` の件数も必ず報告する。

## 5. 再評価のしかた

1. 保存したAPIレスポンス（`data/private/`）を今の版で採点し直す：`node data/rescore.mjs <candidate_id> <response.json> >> data/private/scores.csv`
2. 人の選好と比べる：`node data/agreement.mjs data/private/preferences.csv data/private/scores.csv`（版ごと・dev/holdoutごとに集計）
3. holdout（約30%）は重みや閾値の調整に使わない。20件程度なので一致率は参考値とする。
